# DCG GROUP — Official Ecosystem Website

Website mẹ giới thiệu hệ sinh thái DCG GROUP: **DCG TALENT**, **DCG STUDIO**, **DCG VISION**, **DCG ENTERTAINMENT**.

- DCG TALENT: sản phẩm DCG GROWMATCH — https://dcg-growmatch.vercel.app
- DCG STUDIO: video AI, CGI, quảng cáo, truyền thông
- DCG VISION: thị giác máy tính, dự án camera Mắt Thần hỗ trợ QA/QC F&B
- DCG ENTERTAINMENT: phim, âm nhạc, nhân vật AI

Công nghệ: Vite, HTML/CSS/JavaScript. Mã nguồn website giới thiệu, không sử dụng khóa API hoặc dữ liệu ứng viên. Bản nhận diện logo riêng đang được đưa từ bộ tài sản được phê duyệt sang dự án.

## Development
```bash
npm install
npm run dev
npm run build
```

## Deployment
Vercel, project `dcg-group`, production branch `main`, output `dist`.

Lưu ý: website DCG GROUP hoàn toàn độc lập với sản phẩm DCG GROWMATCH. Không tự ý công bố số liệu tài chính hoặc khách hàng chưa được xác minh.
